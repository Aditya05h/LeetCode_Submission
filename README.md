# LeetCode — Learning to Think in Code

This repository is my collection of LeetCode solutions while I improve my understanding of Data Structures, Algorithms, and problem-solving.

Not every solution here is perfect or ultra-optimized.

Some are clean.

Some took way too long.

Some made me question whether I actually knew how a `for` loop worked.

And that is exactly why I keep them here.

---

## The Usual Process

```text
Read Problem
    ↓
"This looks easy"
    ↓
Write Code
    ↓
Wrong Answer
    ↓
Debug
    ↓
Find one tiny mistake
    ↓
Accepted
    ↓
Feel like a genius
    ↓
Open next problem
    ↓
"This looks impossible"
```
## Repository Structure

```text
LeetCode/
├── Easy/
├── Medium/
├── Hard/
└── README.md
```
Most solutions are written in Java.

## Why This Repo Exists

I'm not solving problems just to increase a counter.
The goal is to get better at:
```text
Understanding the problem
        ↓
Recognizing patterns
        ↓
Choosing the right approach
        ↓
Writing efficient code
        ↓
Explaining why it works
```
Because getting Accepted is good.
Understanding why it got accepted is better.

## One Rule

I try to struggle with the problem before looking at someone else's solution.
Copying an answer gives you the solution.
Understanding why your approach failed gives you the lesson.
```text
while (!masteredDSA) {
    solve();
    fail();
    debug();
    learn();
    improve();
}
```
Still learning.
Still coding.
Still occasionally losing 20 minutes to one missing semicolon.
